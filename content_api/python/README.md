## Introduction

This sample Python script [content_api_example.py](./content_api_example.py) demonstrates a simple query to the endpoint of the API.

The returned data, in JSON format, would then be consumed by your own custom applications.

## Requirements

Have a valid subscription to the Capital Economics API, see [project docs](../README.md) for more information.

## Usage

Replace the **API_KEY** value with your own api-key credentials.

## Installation

If you don't already have one, it is recommended that a virtual environment be created for your project:

From your project root, for example:

`cd /<project_root_path>/ce_api_examples`

Create the venv

`python3 -m venv .venv`

Activate it

`source .venv/bin/activate`

After activation your prompt will show `(.venv)`. To deactivate later, just run `deactivate`

And once activated, then the dependencies can be installed:

`pip install -r requirements.txt`
